# Markdown Examples

## Общая информация

Этот раздел портфолио предназначен для демонстрации навыков подготовки и оформления технической документации с использованием Markdown.

Markdown используется для создания структурированных документов, которые удобно хранить в системе контроля версий, просматривать непосредственно в GitHub и использовать в подходе Docs as Code.

## Что демонстрирует использование Markdown

Работа с Markdown в рамках портфолио включает:

- построение структуры документа с использованием заголовков;
- оформление нумерованных и маркированных списков;
- работу с таблицами;
- оформление ссылок и изображений;
- оформление inline-кода и блоков кода;
- использование технических терминов и примеров команд;
- хранение и версионирование документации с использованием Git.

## Используемые технологии

- Markdown;
- Git;
- GitHub.
