# Редактирование компании в личном кабинете

## Краткое описание

Личный кабинет SmartPlayer позволяет администраторам изменять данные компании напрямую через пользовательский интерфейс без обращения в техническую поддержку.

## Управление доступом

Редактировать данные компании могут только пользователи с ролью **Администратор**.

## Редактируемые поля

Для редактирования доступны следующие поля:

- аватар компании;
- имя пользователя;
- привязанный email-адрес;
- пароль.

**Название компании** редактируется отдельно через специальный элемент интерфейса.

## Предварительные условия

Перед началом убедитесь, что:

- пользователь зарегистрирован в SmartPlayer;
- пользователь авторизован в личном кабинете;
- пользователь обладает ролью **Администратор**.

## Сценарий работы в интерфейсе

### Редактирование основных данных компании

1. Войдите в личный кабинет SmartPlayer.
2. Нажмите на иконку профиля в левом верхнем углу.
3. В окне с информацией о компании нажмите **Редактировать**.
4. Обновите необходимые поля:
   - аватар компании;
   - имя пользователя;
   - привязанный email;
   - пароль.
5. Нажмите **Обновить**, чтобы сохранить изменения.

### Отмена редактирования

Чтобы отменить несохранённые изменения, нажмите **Закрыть**.

### Изменение названия компании

1. Нажмите на иконку карандаша рядом с названием компании.
2. Введите новое название компании.
3. Нажмите **Сохранить**.

## Ожидаемый результат

После сохранения обновлённые данные компании отображаются в интерфейсе личного кабинета.

## Связанные разделы

- управление профилем пользователя;
- обновление данных компании;
- изменение названия компании;
- управление учётной записью администратора.

EN:
# Company Editing in Personal Account

## Summary

The SmartPlayer personal account provides administrators with the ability to update company-related information directly in the UI without submitting a request to technical support.

## Access Control

Only users with the **Administrator** role can edit company data.

## Editable Fields

The following fields are available for editing:

- company avatar;
- user name;
- linked email address;
- password.

The **company name** is edited separately through a dedicated control.

## Preconditions

Before starting, ensure that:

- the user is registered in SmartPlayer;
- the user is authenticated in the personal account;
- the user has the **Administrator** role.

## UI Flow

### Edit company profile data

1. Log in to the SmartPlayer personal account.
2. Click the profile icon in the upper-left corner.
3. In the company information modal, click **Edit**.
4. Update the required fields:
   - company avatar;
   - user name;
   - linked email;
   - password.
5. Click **Update** to save changes.

### Cancel editing

To discard unsaved changes, click **Close**.

### Edit company name

1. Click the pencil icon next to the company name.
2. Enter a new company name.
3. Click **Save**.

## Expected Result

After saving, the updated company data is displayed in the personal account UI.
