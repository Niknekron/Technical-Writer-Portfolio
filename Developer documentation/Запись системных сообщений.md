# Запись системных сообщений в общий файл журнала сообщений

## Краткое описание

SmartPlayer поддерживает запись системных сообщений операционной системы в общий файл журнала сообщений клиентского приложения. Эта возможность используется для диагностики ошибок устройства и анализа проблем, возникающих во время его работы.

На текущий момент функциональность реализована только для устройств под управлением **Android OS**.

## Назначение

Функция позволяет разработчику клиентского приложения получать доступ к системным сообщениям устройства через журнал, чтобы:

- анализировать ошибки операционной системы;
- диагностировать нестабильную работу устройства;
- собирать дополнительную техническую информацию для отладки.

## Область применения

Функциональность доступна только для устройств на **Android OS**.

## Предварительные условия

Перед настройкой убедитесь, что:

- пользователь авторизован в личном кабинете SmartPlayer;
- устройство уже добавлено в раздел **Устройства**;
- у пользователя есть доступ к настройкам устройства.

## Сценарий работы в интерфейсе

1. Войдите в личный кабинет SmartPlayer.
2. Перейдите в раздел **Устройства**.
3. Выберите нужное устройство, не используя чекбокс в левом верхнем углу плитки устройства.
4. В открывшемся тулбаре справа выберите раздел **Настройки**.
5. В разделе **Настройки** откройте категорию **Разработка**.
6. Настройте параметры категории **Разработка**:
   - включите или отключите параметр **Записывать сообщения операционной системы**;
   - выберите один из доступных уровней логирования:
     - `Trace`
     - `Debug`
     - `Info`
     - `Warn`
7. Нажмите **Сохранить изменения**, чтобы применить настройки.

## Уровни логирования

Для уровней логирования `Trace` и `Debug` используется следующее предупреждение:

> Включать для получения дополнительных записей в журнал устройства по работе операционной системы. Чаще всего актуально в режиме Debug и Trace. Будет дополнительная нагрузка на устройство. Если устройство слабое, использовать под наблюдением.

## Значение по умолчанию

По умолчанию для записи системных сообщений может использоваться уровень логирования **Debug** или **Trace**.

## Ожидаемый результат

После сохранения настроек устройство начинает записывать системные сообщения операционной системы в общий файл журнала сообщений клиентского приложения в соответствии с выбранным уровнем логирования.

# Recording System Messages to the Shared Message Log File

## Summary

SmartPlayer supports recording operating system messages to the shared message log file of the client application. This feature is used for device error diagnostics and troubleshooting during device operation.

At the moment, this functionality is available only for devices running **Android OS**.

## Purpose

This feature allows a client application developer to access device system messages through the log in order to:

- analyze operating system errors;
- diagnose unstable device behavior;
- collect additional technical data for debugging.

## Scope

This functionality is supported only for devices running **Android OS**.

## Preconditions

Before configuring this feature, make sure that:

- the user is authenticated in the SmartPlayer personal account;
- the device has already been added to the **Devices** section;
- the user has access to device settings.

## UI Flow

1. Sign in to the SmartPlayer personal account.
2. Open the **Devices** section.
3. Select the required device without using the checkbox in the upper-left corner of the device tile.
4. In the toolbar displayed on the right, open **Settings**.
5. In the **Settings** section, open the **Development** category.
6. Configure the **Development** parameters:
   - enable or disable **Record operating system messages**;
   - select one of the available logging levels:
     - `Trace`
     - `Debug`
     - `Info`
     - `Warn`
7. Click **Save changes** to apply the configuration.

## Logging Levels

The following warning is displayed for the `Trace` and `Debug` logging levels:

> Enable this option to collect additional device log records related to operating system activity. This is most commonly used in Debug and Trace modes. This option adds extra load to the device. If the device has limited performance, use it with caution.

## Default Value

By default, the logging level for recording system messages may be set to **Debug** or **Trace**.

## Expected Result

After the settings are saved, the device starts writing operating system messages to the shared message log file of the client application according to the selected logging level.
