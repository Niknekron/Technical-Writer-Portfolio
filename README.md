# Technical Writer Portfolio

Портфолио технического писателя с примерами пользовательской и технической документации, API-документации, диаграмм и материалов, подготовленных с использованием различных форматов документирования.

## Обо мне

Я — технический писатель, специализирующийся на документации для программных продуктов.

В работе занимаюсь сбором и структурированием технической информации, подготовкой пользовательской и технической документации, описанием функциональности программных продуктов и взаимодействием с техническими специалистами.

В портфолио представлены как рабочие материалы, опубликованные с учетом ограничений NDA, так и демонстрационные примеры, созданные для подтверждения навыков работы с различными форматами и инструментами документирования.

## Основные компетенции

- пользовательская документация;
- техническая документация;
- документация для разработчиков;
- REST API documentation;
- Swagger / OpenAPI;
- Markdown;
- AsciiDoc;
- YAML;
- Git / GitHub;
- UML;
- BPMN;
- PlantUML;
- подготовка технических схем и диаграмм;

## Содержание портфолио

Пример пользовательской документации для программного продукта.

Материалы демонстрируют:

- описание пользовательских сценариев;
- пошаговые инструкции;
- структурирование сложной функциональности;
- работу с интерфейсом программного продукта;
- подготовку документации для конечных пользователей.

### Developer documentation

Примеры технической документации, подготовленной в рамках работы с программным продуктом.

Материалы демонстрируют:

- описание технической функциональности;
- работу с системными параметрами и настройками;
- подготовку документации для технической аудитории;
- преобразование технической информации в структурированный документ.

---

### API Documentation Examples

Демонстрационные примеры документации REST API.

Раздел содержит примеры работы с:

- HTTP-методами;
- endpoints;
- query- и body-параметрами;
- структурами запросов и ответов;
- YAML;
- Swagger / OpenAPI.

Для подготовки материалов использованы публичные API.

---

### AsciiDoc Examples

Пример технической документации, подготовленной с использованием AsciiDoc.

Раздел демонстрирует:

- работу с AsciiDoc;
- описание HTTP-сервиса;
- структурирование технической документации;
- генерацию документации в HTML;
- использование PlantUML совместно с текстовой документацией.

---

### Diagrams

Примеры технических схем и диаграмм.

В разделе представлены материалы с использованием:

- UML;
- BPMN;
- PlantUML;
- Draw.io.

Диаграммы используются для визуализации процессов, взаимодействия компонентов и логики работы систем.

---

### Markdown Examples

Раздел с примерами использования Markdown для подготовки технической документации.

Демонстрируются:

- структура Markdown-документов;
- таблицы и списки;
- ссылки и изображения;
- inline-код и блоки кода;
- хранение документации в Git.

## О материалах

Часть представленной документации основана на реальных рабочих задачах.

Материалы, связанные с коммерческими проектами, представлены только в объеме, допустимом для публичного размещения, и не содержат конфиденциальных данных.

Демонстрационные примеры API и отдельных технологий созданы специально для портфолио либо основаны на общедоступных данных.

## Цель репозитория

Репозиторий создан как публичное портфолио и демонстрирует практические навыки подготовки, структурирования и оформления технической документации для программных продуктов.
