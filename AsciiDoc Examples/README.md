# AsciiDoc Documentation Example

## Общая информация

В этом разделе портфолио представлен демонстрационный пример технической документации, подготовленной с использованием AsciiDoc.

Документация описывает HTTP-сервис для работы с задачами и связанные с ним структуры данных.

## Состав раздела

Основная директория содержит:

- `index.adoc` — исходный файл технического описания HTTP-сервиса;
- `index.html` — сгенерированная HTML-версия документации;
- `db/` — материалы с описанием структуры данных.

В директории `db` представлены:

- `db.adoc` — исходный документ в формате AsciiDoc;
- `db.html` — HTML-версия документа;
- `db.puml` — исходный код диаграммы PlantUML;
- `db.png` — визуальное представление диаграммы.

## Описание примера

HTTP-сервис поддерживает основные операции для работы с задачами:

- создание задачи — `POST`;
- получение списка задач — `GET`;
- получение отдельной задачи — `GET`;
- изменение задачи — `PUT`;
- удаление задачи — `DELETE`.

## Что демонстрируют материалы

Представленный пример демонстрирует навыки:

- работы с AsciiDoc;
- подготовки структурированной технической документации;
- документирования HTTP-сервисов;
- описания методов работы с данными;
- подготовки документации в исходном и HTML-форматах;
- использования PlantUML для визуализации технической информации;
- хранения исходных файлов документации в Git.
