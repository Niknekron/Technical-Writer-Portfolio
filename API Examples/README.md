# API Documentation Examples

## Общая информация

В этом разделе портфолио представлены демонстрационные примеры документации REST API.

Материалы показывают навыки работы с HTTP-методами, endpoints, параметрами запросов, структурами запросов и ответов, а также форматами Markdown, YAML и OpenAPI/Swagger.

Для подготовки примеров использованы публичные API.

## Состав раздела

### Examples API

В директории представлены примеры описания отдельных элементов REST API:

- `API Example 1.markdown` — описание query-параметра `since` для endpoint `GET /organizations` GitHub REST API;
- `API Example 2.yaml` — описание body-параметра `email` для endpoint `POST /v1/customers` Stripe API.

### Swagger examples

В директории представлен пример спецификации API в формате OpenAPI/Swagger:

- `ExamplesOpenWeatherAPI's.yaml` — описание OpenWeather API с параметрами запросов, схемами объектов ответа и механизмом авторизации.

## Что демонстрируют материалы

Представленные примеры демонстрируют навыки:

- документирования REST API;
- работы с HTTP-методами и endpoints;
- описания query- и body-параметров;
- подготовки примеров запросов и ответов;
- работы с YAML;
- работы с OpenAPI/Swagger;
- структурирования технической информации для разработчиков и интеграторов.
