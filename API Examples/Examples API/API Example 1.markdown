# Параметр `since`

## Общая информация

**API:** GitHub REST API  
**Endpoint:** `GET /organizations`  
**Base URL:** `https://api.github.com`  

Возвращает список организаций GitHub в порядке их создания.

## Расположение параметра

**Имя:** `since`  
**Где передаётся:** `query`  
**Тип:** `integer`  
**Обязательный:** нет  

## Назначение

Параметр `since` задаёт идентификатор организации, начиная **после** которого нужно вернуть данные.

Если в запросе передать `since=100`, сервер вернёт только те организации, у которых `id` больше `100`.

## Для чего используется

Параметр `since` используется для пагинации.

Этот endpoint постранично отдает данные именно через `since`.  
Чтобы получить следующую часть результатов, клиент использует значение из предыдущего ответа и заголовок `Link`.

## Пример запроса

```http
GET /organizations?since=100 HTTP/1.1
Host: api.github.com
Accept: application/vnd.github+json
